# 💼 HireLoop - Job Seeking Platform

A modern full-stack job seeking platform that connects job seekers with employers. Users can search and apply for jobs, while employers can post job vacancies and manage applications through a secure dashboard.

# 📖 Project Overview

HireLoop is a full-stack MERN-based job portal designed to simplify the recruitment process. The platform provides separate dashboards for Job Seekers and Employers with secure authentication, job management, application tracking, and profile management.

The application focuses on providing a fast, responsive, and user-friendly experience while maintaining secure access control using JWT authentication and HTTP-only cookies.
